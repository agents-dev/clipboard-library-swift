# Use skill and file notes

- Click + in Notes. Paste a public GitHub repository, folder, or SKILL.md URL. Click Import.
- Expand the imported folder. Double-click a skill to paste its Markdown file into the previous application. Use a destination that accepts file paste.
- Import https://github.com/openai/plugins/tree/main/plugins/build-macos-apps to create a build-macos-apps parent with its skill children. Paste build-run-debug as build-run-debug.md.
- Copy individual files in Finder. Select a note and press Command-V to attach files as children. Click blank Notes space before pasting when the panel is empty. Use the clipboard button for the same action.
- Keep each file at or below 25 MB and each batch at or below 100 MB. Paste individual files instead of folders.
- Double-click an attached file to paste a stored copy. Keep using the attachment after moving or deleting the source file.
- Open the Notes ellipsis menu and select Add text note to create an ordinary note. Paste text normally while editing it.
- Enable Accessibility for automatic paste, or press Command-V in the destination after double-clicking.
- Retain exported copies in the application-support ClipboardLibrary/Exports directory while destination apps use them. Treat these copies as unencrypted files.
